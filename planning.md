# Project Proposal

## Business Case

### Problem statement
Finding information about parks and green spaces in Bristol can be difficult when users do not know where to find reliable information about available locations. The Bristol Parks Explorer project aims to address this problem by developing a centralised, user-friendly web application that allows users to discover, search, filter and explore parks and green spaces across Bristol. Therefore, information about Bristol's public green spaces are easier to access, understand and navigate.

### Business benefits
Improved accessibility: Makes information about Bristol's parks and green spaces easier for the public to find.
Better user experience: Provides a simple and organised way to explore available green spaces.
Increased awareness: Encourages people to discover parks and outdoor spaces they may not have visited before.
Efficient information access: Brings relevant park information together in one place.

### Options Considered
Google Maps: Users can search for parks and green spaces, view locations on a map, and access directions.
Bristol City Council website: Provides official information about parks, gardens, and other green spaces in Bristol.
Go Jauntly: a walking app that helps users discover parks, green spaces and walking routes.

### Expected Risks
Data accuracy: Park information may be outdated or incomplete.
Data availability: The dataset or external data source may not provide all the information required.
Poor user experience: Users may find the website difficult to navigate if the design is unclear.

## Project Scope
Features in the scope:
Displaying information about parks and green spaces in Bristol.
Retrieving and presenting park information from an available dataset.
Using HTML, CSS, and JavaScript to develop the website.
Presenting park information in a clear and organised format.
Allowing users to access the website through a web browser.
Providing a simple, user-friendly interface.

Features outside the scope:
Creating user accounts or login systems.
Booking park facilities or activities.
Allowing users to submit reviews or ratings.
Providing live information about park conditions or events.
Developing a dedicated mobile application
